# Hi, I'm VAIO73

I build practical tools for Windows admins, homelab users, and people who
manage servers, networks, and remote systems every day.

My projects usually focus on calm interfaces, portable workflows, SSH
automation, network diagnostics, monitoring, and Proxmox / homelab operations.

## Current Focus

- **TermHub** - portable SSH workspace for Windows admins
- **QuickSSH** - Flow Launcher plugin for SSH profiles and remote actions
- **MultiPingMonitor** - portable Windows network monitor
- **WinPerf** - modern GUI for iperf3 throughput testing
- **ProxMenux contributions** - Proxmox tooling, Monitor fixes, and workflow polish
